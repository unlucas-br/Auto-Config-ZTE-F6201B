# Atuamax — Personalizador F6201B

Tema laranja com logo Atuamax, saudação **“Bem-vindo, cliente Atuamax.”**, menus reorganizados e RSSI atualizado a cada 2 segundos em **Rede local > Status**.

- [Baixar pacote Windows 64 bits](Atuamax_Windows_x64.zip)
- Executável após extrair: `Personalizador_F6201B.exe`
- Firmware compatível: `V9.3.10P7N6` e `V9.3.10P7N7` com imagem base validada.
- Nome Wi-Fi opcional: `Atuamax_XXXX`; senhas preservadas.

Extraia o ZIP inteiro e consulte o [guia de uso](../README.md#uso). O código-fonte, os perfis e os recursos das duas versões estão nesta pasta. Os backups criados pelo programa permanecem locais.
